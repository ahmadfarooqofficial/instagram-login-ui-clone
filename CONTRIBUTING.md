## 🛣️ How Can I Contribute?

### 🐛 1. Reporting Bugs & Suggesting Features
Before opening a new issue, please search the existing [Issues](https://github.com/AhmadFarooq/instagram-login-ui-clone/issues) to see if it has already been discussed. If not:
- Open a new issue describing the bug or feature request.
- Include steps to reproduce the issue, browser version, and screen size context if applicable.

### 💻 2. Contributing Code (Pull Requests)
We follow a standard GitHub Fork-and-Pull workflow to merge contributions. Follow these steps to get your changes merged:

#### Step 1: Fork the Repository
Click the **Fork** button at the top-right corner of the [main repository page](https://github.com/AhmadFarooq/instagram-login-ui-clone) to create a copy of the codebase under your own GitHub account.

#### Step 2: Clone Your Fork
Clone the forked repository to your local development machine:
```bash
git clone https://github.com/your-username/instagram-login-ui-clone.git
cd instagram-login-ui-clone
```

#### Step 3: Create a Dedicated Branch
Create a new branch with a short, descriptive name representing your change (e.g., `fix/floating-label-overflow` or `feature/accessibility-tags`):
```bash
git checkout -b feature-or-fix-name
```

#### Step 4: Make Your Changes & Test
Edit the codebase using your preferred IDE. Since this is a zero-dependency vanilla project:
- Ensure all styling aligns with the native Instagram pixel-perfect guidelines.
- Test your changes locally on multiple simulated device viewports (desktop, tablet, mobile).
- Double-check that you did not introduce external libraries or scripts. Keep it **100% pure vanilla HTML, CSS, and JavaScript**.

#### Step 5: Commit Your Changes
Write clear, meaningful commit messages that explain *what* you changed and *why*:
```bash
git commit -m "style: fix input alignment on Safari mobile viewports"
```

#### Step 6: Push to Your Fork
Push your local branch to your GitHub repository fork:
```bash
git push origin feature-or-fix-name
```

#### Step 7: Create a Pull Request (PR)
1. Navigate to the original [AhmadFarooq/instagram-login-ui-clone](https://github.com/AhmadFarooq/instagram-login-ui-clone) repository on GitHub.
2. You will see a banner prompting you to create a **Pull Request** from your newly pushed branch.
3. Click **Compare & pull request**.
4. Fill out the PR template with details about what your changes accomplish.
5. Submit your PR!

## 🎨 Code Style & Quality Guidelines

To maintain a pixel-perfect standard, please keep the following guidelines in mind:
- **Keep it Vanilla:** Absolutely no external dependencies (Bootstrap, Tailwind, jQuery, React, etc.). Only vanilla CSS3 and vanilla JS are permitted.
- **Maintain Performance:** Preserve high-speed techniques such as element preloading and minimal layout paints.
- **Browser Compatibility:** Test your styles to ensure they render beautifully across all evergreen modern browsers (Chrome, Safari, Firefox, Edge).
- **Semantics:** Use standard HTML5 elements to keep the document structurally sound and screen-reader accessible.
